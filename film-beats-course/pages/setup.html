Setup — do this before Week 1

Signal chain — a correction to the original plan

The obvious plan is a laptop/TV headphone out into the SP's INPUT jack. That works, but there's a better option: the SP-404MK2 accepts USB audio input. Set your laptop's audio output device to the SP-404MK2 and its playback arrives digitally, with no analogue noise, no impedance mismatch, and no hot-headphone-out level problem verified — Roland/Sweetwater document sampling directly from the USB input.

This does not compromise the principle. The laptop is a playback source, not a DAW in the signal path — same role a record player has for a crate digger.

Three routing options, in order of preference

  1. USB. Laptop → SP USB port. Set laptop output to SP-404MK2. Cleanest.
  2. Line. Laptop/TV headphone out → SP LINE IN. Start with the laptop volume at about 30% and raise it; headphone outs are hot and will clip the SP's input.
  3. Zoom H4. Record off a speaker or via line, transfer the WAV by SD card and import. Slowest, but it's how you'd capture a cinema screening or a VHS deck with no clean output.

One-time SP settings

  1. SHIFT + pad 13 → UTILITY screen. verified
  2. [VALUE] knob → select SYSTEM → press [VALUE].
  3. Turn [CTRL 3] to move between tabs. You want:
    • MIDI tab — for Week 4 sync.
    • MARK Function — set to if available. This raises skip-back memory from 25 to 40 seconds verified — extended in firmware v2.00.
  4. [EXIT] to back out.
Skip-back sampling and the looper cannot both be active. They share the [MARK] button. SHIFT + press [VALUE] knob toggles between them verified. If skip-back isn't working, this is the first thing to check.
